Conflict Data: How to get from raw events → NUTS2?

ACLED provides events with lat/lon. Two approaches to aggregate to NUTS2 level.

A

Spatial Join (Recommended)

Download ACLED CSV + Eurostat NUTS2 shapefiles → geopandas point-in-polygon → exact NUTS2 assignment per event → aggregate to density.

Pros

  • Academically defensible — events assigned to correct region
  • Works for cross-border regions and small countries (e.g. BE/NL/LU)
  • Enables future spatial analysis (distance to border, cluster maps)
  • Reuses Eurostat shapefile for Phase 2B graph construction

Cons

  • Requires geopandas + pyogrio in environment.yml
  • Shapefile join adds ~3–5 min to pipeline runtime
  • More complex script to implement and test

Pipeline: ACLED CSV → gpd.sjoin with NUTS2 shapefile → groupby nuts2_code → events/100k

Needs: ACLED Europe CSV (manual export) + NUTS2 shapefile (Eurostat bulk download)

B

Country-Proportional Allocation

Download ACLED CSV → aggregate to country × year → distribute to NUTS2 proportionally by population share.

Pros

  • No shapefile or geopandas needed
  • Faster to implement and test
  • Simpler pipeline — pure pandas

Cons

  • Methodologically weak — assumes uniform conflict distribution within a country
  • Misrepresents reality: e.g. Ukraine border events assigned equally to all Polish NUTS2
  • Undermines CEI signal — a German fab 20km from Ukraine border looks same as Munich
  • Hard to defend in a thesis methods section

Pipeline: ACLED CSV → groupby country, year → merge NUTS2 population shares → events/100k

Needs: ACLED Europe CSV only
