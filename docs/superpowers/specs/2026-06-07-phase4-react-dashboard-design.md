# Phase 4 — React Dashboard Design

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a static React dashboard that visualises the GNN anomaly scores for 242 EU NUTS2 regions (2010–2023), deployable as a zero-dep static site and fully reproducible from the Python pipeline outputs.

**Architecture:** Three-panel layout — EU choropleth map (left, ~50%) | region time series with neighbour overlay (middle, ~25%) | top-25 ranking with sparklines (right, ~25%). Dark theme. Scaffolded from `RO-Administrative-Reform/dashboard` (same Vite + React 18 + TS + react-leaflet + Recharts + Tailwind stack).

**Tech Stack:** Vite 5, React 18, TypeScript 5, react-leaflet 4, Recharts 2, Tailwind 3, gh-pages. Data: static JSON + GeoJSON in `dashboard/public/data/`.

```python
g = torch.load('data/processed/nuts2_graph.pt', weights_only=False)
```

## 4. TypeScript Types (`src/types.ts`)

```typescript
export interface RiskScore {
  nuts2_code: string;
  country_code: string;
  year: number;
  anomaly_score: number;
  peak_score: number;
  peak_rank: number;
}

export interface RegionTimeSeries {
  nuts2_code: string;
  country_code: string;
  peak_score: number;
  peak_rank: number;
  peak_year: number;  // year with max anomaly_score
  scores: { year: number; anomaly_score: number }[];
}

export interface DashboardData {
  scores: RiskScore[];
  neighbours: Record<string, string[]>;
  geoJson: GeoJSON.FeatureCollection;           // raw NUTS2 GeoJSON — passed to EuropeMap
  regionNames: Record<string, string>;          // nuts2_code → NAME_LATN (from GeoJSON)
  byCode: Record<string, RegionTimeSeries>;     // nuts2_code → RegionTimeSeries
  byYear: Record<number, Record<string, number>>;  // year → {nuts2_code → anomaly_score}
  maxScore: number;
  systemPeakYear: number;   // year with highest mean anomaly across all regions
  topRegions: RegionTimeSeries[];   // sorted by peak_score descending
  countries: string[];   // sorted unique country_code list
}
```

## 5. Data Hook (`src/hooks/useDashboardData.ts`)

```typescript
import { useEffect, useState } from 'react';
import type { RiskScore, RegionTimeSeries, DashboardData } from '../types';

const BASE = import.meta.env.BASE_URL;

async function fetchJson<T>(name: string): Promise<T> {
  const res = await fetch(`${BASE}data/${name}`);
  if (!res.ok) throw new Error(`Failed to fetch ${name}: ${res.status}`);
  return res.json() as Promise<T>;
}

export function useDashboardData(): { data: DashboardData | null; error: string | null } {
  const [data, setData] = useState<DashboardData | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    Promise.all([
      fetchJson<RiskScore[]>('risk_scores.json'),
      fetchJson<Record<string, string[]>>('neighbours.json'),
      fetchJson<GeoJSON.FeatureCollection>('nuts2.geojson'),
    ])
      .then(([scores, neighbours, geoJson]) => {
        // Extract region names from GeoJSON (NAME_LATN property)
        const regionNames: Record<string, string> = {};
        for (const f of (geoJson as GeoJSON.FeatureCollection).features) {
          const p = (f as { properties: { NUTS_ID: string; NAME_LATN: string } }).properties;
          regionNames[p.NUTS_ID] = p.NAME_LATN;
        }

        // Build byCode: nuts2_code → RegionTimeSeries
        const codeMap = new Map<string, RiskScore[]>();
        for (const s of scores) {
          if (!codeMap.has(s.nuts2_code)) codeMap.set(s.nuts2_code, []);
          codeMap.get(s.nuts2_code)!.push(s);
        }

        const byCode: Record<string, RegionTimeSeries> = {};
        codeMap.forEach((rows, code) => {
          const sorted = rows.slice().sort((a, b) => a.year - b.year);
          const peakRow = sorted.reduce((a, b) => (a.anomaly_score > b.anomaly_score ? a : b));
          byCode[code] = {
            nuts2_code: code,
            country_code: rows[0].country_code,
            peak_score: rows[0].peak_score,
            peak_rank: rows[0].peak_rank,
            peak_year: peakRow.year,
            scores: sorted.map((r) => ({ year: r.year, anomaly_score: r.anomaly_score })),
          };
        });

        // byYear: year → {nuts2_code → anomaly_score}
        const byYear: Record<number, Record<string, number>> = {};
        for (const s of scores) {
          if (!byYear[s.year]) byYear[s.year] = {};
          byYear[s.year][s.nuts2_code] = s.anomaly_score;
        }

        const maxScore = Math.max(...scores.map((s) => s.anomaly_score));

        // systemPeakYear: year with highest mean anomaly
        const yearMeans = Object.entries(byYear).map(([yr, m]) => ({
          year: Number(yr),
          mean: Object.values(m).reduce((a, b) => a + b, 0) / Object.values(m).length,
        }));
        const systemPeakYear = yearMeans.reduce((a, b) => (a.mean > b.mean ? a : b)).year;

        const topRegions = Object.values(byCode).sort((a, b) => a.peak_rank - b.peak_rank);
        const countries = [...new Set(scores.map((s) => s.country_code))].sort();

        setData({ scores, neighbours, geoJson, regionNames, byCode, byYear, maxScore, systemPeakYear, topRegions, countries });
      })
      .catch((e: unknown) => setError(e instanceof Error ? e.message : String(e)));
  }, []);

  return { data, error };
}
```

## 6. Color Utility (`src/utils/color.ts`)

Sequential scale: dark-blue (low) → amber (mid) → red (high) → purple (top).

```typescript
function lerp(a: number, b: number, t: number): number {
  return Math.round(a + (b - a) * t);
}

function hexToRgb(hex: string): [number, number, number] {
  const v = parseInt(hex.slice(1), 16);
  return [(v >> 16) & 255, (v >> 8) & 255, v & 255];
}

function rgbToHex(r: number, g: number, b: number): string {
  return '#' + [r, g, b].map((x) => x.toString(16).padStart(2, '0')).join('');
}

const STOPS: [number, string][] = [
  [0.00, '#1e3a5f'],  // dark blue — low anomaly
  [0.40, '#f59e0b'],  // amber — moderate
  [0.75, '#ef4444'],  // red — high
  [1.00, '#7c3aed'],  // purple — extreme
];

export function anomalyColor(score: number, maxScore: number): string {
  if (maxScore === 0) return STOPS[0][1];
  const t = Math.min(score / maxScore, 1);
  for (let i = 1; i < STOPS.length; i++) {
    const [t0, c0] = STOPS[i - 1];
    const [t1, c1] = STOPS[i];
    if (t <= t1) {
      const u = (t - t0) / (t1 - t0);
      const [r0, g0, b0] = hexToRgb(c0);
      const [r1, g1, b1] = hexToRgb(c1);
      return rgbToHex(lerp(r0, r1, u), lerp(g0, g1, u), lerp(b0, b1, u));
    }
  }
  return STOPS[STOPS.length - 1][1];
}

export const SCORE_STOPS = STOPS;  // exported for legend
```

```typescript
}
```

Content when a region is selected:
- Region name (`data.regionNames[nuts2_code]`, fall back to `nuts2_code`) + country code + peak rank badge
- Recharts `LineChart`: X = year (2010–2023), Y = anomaly_score
- Series:
  1. Selected region: thick red/amber line (colour = `anomalyColor(peak_score, maxScore)`)
  2. Up to 3 spatial neighbours: thin, dashed, semi-transparent grey lines, each labelled by code in the legend
  3. EU mean: thin dashed white line (computed as mean anomaly_score across all regions per year)
- `ReferenceLine` at `x={activeYear}` (vertical, blue, follows slider)
- Y-axis: 0 → `maxScore * 1.1`

Content when no region selected:
- Top-3 risk regions' trajectories (same chart, labelled by code)
- Subtitle: "Click a region on the map to compare it with its GNN graph neighbours"

## 16. Methodological Notes for Dashboard

- **Anomaly score interpretation displayed in UI**: tooltip text states "MSE of GNN reconstruction — higher score = region diverges more from its graph neighbours"
- **Neighbour overlay justification**: showing the GNN graph neighbours' trajectories directly illustrates the anomaly detection mechanism — the viewer sees *why* a region is flagged
- **Colour scale non-linearity**: the blue→amber→red→purple scale is perceptually chosen to emphasise the top tail (few regions, very high scores) without compressing the middle range
- **Year slider vs peak score view**: year slider shows point-in-time anomaly; the ranking always uses peak_score (max over all years) for stable ordering
